# 等待戈多

[点击直接试玩](https://lih42534-wq.github.io/waiting-for-godot/)

一个关于等待、孤独与片刻陪伴的中文像素叙事游戏。

## 玩法

点击「坐一会儿」开始。点击风景探索，对话点击「继续」或按空格、回车。每幕观察三个场景点后出现推进故事的按钮。可以静坐、查看手记、暂停或关闭声音。第一幕点击「静坐片刻」后，可随时选择「进入第二幕」，也可以继续静坐或返回探索。

两幕分别是「今天还会来吗」和「留一点温度」。第二幕包含绿皮火车进站、风尘仆仆的中年旅客、夜风与热水的对话，以及三个结尾回应。

云层、枝叶、落叶持续运动；人物对白时转头，第二幕夜色更深，站灯偶尔轻闪。支持系统减少动态效果设置。环境声通过 Web Audio 本地合成，无第三方运行时或网络音频依赖。

## 本地运行

在仓库根目录运行 `python3 -m http.server 4173`，打开 http://127.0.0.1:4173/ 。Canvas 图层需要通过 HTTP 服务访问。刷新页面会重新开始游戏。

## 部署

GitHub Pages 直接发布 main 分支的根目录。更新后推送到 main，Pages 会自动重新部署。

素材由内置绘图工具生成，人物、列车、云层及树冠通过 Canvas 分层合成。
